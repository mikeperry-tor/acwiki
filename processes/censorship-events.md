---
title: Censorship Events
---
We track censorship events as issues in the [censorship analysis project](https://gitlab.torproject.org/tpo/anti-censorship/censorship-analysis/-/issues/). Those issues are scoped as best as we can to a concrete event or for places where censorship is a continuum we create yearly issues, so we can close the old ones and they don't stay for ever.

For events that we are tracking but we don't plan to produce a response put the issue in status *Not Schedule*.

For the response to an event we create an issue in the [team project](https://gitlab.torproject.org/tpo/anti-censorship/team/-/issues/) (or whatever project might be appropriate) and add it to the epic tpo/anti-censorship#1. Leaving the *censorship analysis* issues for tracking the event, just linking the issues. We add the appropriate ~"Priority::Medium" label to those response issues.

In many occasions this process will be leaded by the Community Team, as they will often create the issues and assign the first priority.
